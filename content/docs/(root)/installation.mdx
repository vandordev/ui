## Prerequisites

Use a React project with Tailwind CSS and shadcn configured. If you have not initialized shadcn yet, run:

```bash
pnpm dlx shadcn@latest init
```

See the [shadcn installation guide](https://ui.shadcn.com/docs/installation) for framework-specific setup.

## Install a Component

Install a registry item using its published JSON URL. Start with the standard shadcn Button baseline:

```bash
pnpm dlx shadcn@latest add https://vandor-ui.vercel.app/r/button.json
```

The CLI copies the component source into your project. You can edit the installed file directly.

```tsx
import { Button } from "@/components/ui/button";

export function Demo() {
  return <Button variant="outline">Button</Button>;
}
```

The import path above assumes the default `@/components/ui` alias. Use your project's configured UI alias if it differs.

If your project already has a Button, review the CLI's overwrite prompt before replacing it. See the [Button documentation](/docs/components/button) for variants, sizes, and source code.

## Develop Vandor UI Locally

To contribute components or documentation, clone the repository:

```bash
git clone https://github.com/vandordev/ui.git
cd ui
pnpm install
pnpm dev
```

Open `http://localhost:3000` to preview the website.

### Add a Registry Component

1. Create its source file under `registry/new-york/`.
2. Add an item to `registry.json`, including dependencies and file targets.
3. Create its documentation under `content/docs/components/` and update navigation in `meta.json`.
4. Generate the registry output:

```bash
pnpm registry:build
```

### Verify Before Publishing

```bash
pnpm check
pnpm build
pnpm typecheck
```

The production build also rebuilds the registry. Deploying the website serves the generated component JSON under `/r/`.
