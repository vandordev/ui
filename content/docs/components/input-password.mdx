## Usage

```tsx
import { InputPassword } from "@/components/ui/input-password";

<InputPassword label="Password" autoComplete="current-password" />;
```

Set `autoComplete="new-password"` for account creation. The default visibility is hidden.

## Behavior & Accessibility

The show/hide button has a changing accessible name and does not submit a form. Existing password-manager attributes are forwarded. This component does not enforce password policy or strength.
