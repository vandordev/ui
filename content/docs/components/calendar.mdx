## Usage

```tsx
import { Calendar } from "@/components/ui/calendar";

<Calendar mode="single" selected={date} onSelect={setDate} />;
```

`Calendar` preserves react-day-picker's discriminated selection modes, localization, date matchers, and component overrides.

## Motion

Vandor adds a directional 8px slide/fade on month changes (200ms), a selection-highlight transition (160ms), and press feedback (120ms, scale 0.96). There is no entrance animation or staggered day reveal. Month changes update the existing container rather than rendering duplicate grids. Selection and callbacks remain immediate.

Set `motion={false}` to disable these animations. System `prefers-reduced-motion` disables them automatically, including press scaling. Custom `components` replace the corresponding Vandor behavior. DayPicker's separate `animate` prop requires its own animation CSS; it is not needed for Vandor motion.

The playground's generated code reproduces configuration, not the dates/month reached through interaction. Reset restores configuration and clears transient selection/navigation.

## Consumer setup

Use React 19, Tailwind CSS 4, Motion 12, and React DayPicker 10. Include your installed UI directory in Tailwind source scanning and provide the standard shadcn theme tokens. The default cell size is 36px; override it with `className="[--cell-size:2.75rem]"`. No DayPicker stylesheet is required for Vandor's default styling/motion.

Calendar installs as one UI file in your configured UI directory. Its shadcn-inspired native buttons are self-contained: it does not install or overwrite Vandor Button or Loading. Base UI's `useRender` composes the native refs/handlers with Motion gestures. For manual installation, install all declared packages and copy Source into your UI directory with the theme setup above.

## Behavior & Accessibility

Use keyboard navigation to move between dates and months. `disabled` matchers prevent selection; `startMonth` and `endMonth` constrain navigation but do not independently disable dates.

`selected` and `onSelect` are controlled and mode-specific: `Date | undefined`, `Date[] | undefined`, or `DateRange | undefined`. Clearing is allowed unless `required` is set. Omitting `mode` renders a calendar without selection, not an implicit single-select calendar. Use `month`/`onMonthChange` for controlled navigation, or `defaultMonth` for an initial month.

Arrow keys move day focus; Page Up/Down changes months. Dropdowns retain native select semantics and visible focus rings. Date buttons preserve native refs and caller event handlers. Calendar does not submit a form field; serialize selection explicitly in your application.

Dates represent calendar days in the local timezone unless `timeZone` is supplied. Locale changes visible and accessible labels; `weekStartsOn` overrides the locale's first weekday. Keep timezone handling consistent when persisting dates, rather than treating a local midnight as a universal UTC date.
