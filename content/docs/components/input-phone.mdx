## Usage

```tsx
import { InputPhone } from "@/components/ui/input-phone";

<InputPhone
  label="Phone number"
  defaultCountry="ID"
  value={phone}
  onValueChange={setPhone}
/>;
```

The default country is Indonesia. The public value contains international digits without a leading plus sign.

The compact calling-code selector stays beside the number field. Its menu shows localized country names and calling codes. Floating labels rise to a notch in the top border of the compact 40px control; use `labelStyle="static"` for a conventional label.

## Behavior & Accessibility

Country names follow `locale`; the calling-code picker has an accessible name. Partial numbers remain editable and preserve the draft. Formatting does not validate that a number exists, is reachable, or satisfies application rules. Empty input emits `undefined`.
