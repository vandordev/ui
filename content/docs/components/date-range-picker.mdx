## Usage

```tsx
import { DateRangePicker } from "@/components/ui/date-range-picker";

<DateRangePicker
  label="Reporting period"
  value={range}
  onValueChange={setRange}
  features={["twoMonths", "shortcuts"]}
/>;
```

Choose `twoMonths` and `shortcuts` independently. Shortcut ranges include today; weeks begin on Monday by default. Dates represent local calendar days, and range endpoints are inclusive.

This extends shadcn's range composition with Vandor's animated Popover and existing transactional behavior. `motion={false}` disables popup, Calendar, and all button motion. System reduced-motion preferences take priority. Popup reveal is 180ms and exit 120ms; draft/commit callbacks do not wait for animation.

## Consumer setup

Requires React 19.2+, Tailwind CSS 4 and shadcn theme tokens. CLI installation includes Button (and Loading files), Calendar, Popover, and `date-picker-utils.ts`. Review overwrite prompts for customized primitives. Copying Source alone is insufficient: manual installation also needs these registered files/dependencies. No separate animation CSS is required.

## Behavior & Accessibility

The popup opens at the committed range's starting month and focuses an eligible date. Label and displayed value name the trigger; the popup has an accessible title. Two-month mode shows one month below 768px. Popup scrolling respects the available viewport height.

`value` (including explicit `undefined`) is controlled; otherwise `defaultValue` initializes internal state. `open` controls visibility independently. Read-only permits inspection/navigation, disables shortcuts/clear/Apply, and leaves Cancel available. Clearing changes the draft only; Apply commits `undefined`. Incomplete or disabled-date ranges cannot be applied.

The picker is not a native form field; serialize committed values explicitly. Dates are local calendar days; formatting is display-only. Generated playground code reproduces configuration, not transient draft/selection. Reset clears the value and closes the popup.

Calendar edits remain a draft until Apply. Cancel, Escape, and outside dismissal discard the draft. Apply is disabled for incomplete, reversed, or disabled-date ranges. Clearing is an explicit draft when `clearable` is enabled.
