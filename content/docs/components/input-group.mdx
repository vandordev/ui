## Usage

```tsx
import {
  InputGroup,
  InputGroupAddon,
  InputGroupInput,
  InputGroupText,
} from "@/components/ui/input-group";

<InputGroup>
  <InputGroupAddon>
    <InputGroupText>https://</InputGroupText>
  </InputGroupAddon>
  <InputGroupInput label="Website" placeholder="example.com" />
</InputGroup>;
```

`InputGroupAddon` supports inline-start/end and block-start/end placement. Use `InputGroupButton` for an interactive action.

`InputGroupInput` accepts the same label, icon, and native input props as `Input`. Labels default to floating inside the control without a background patch; use `labelStyle="static"` for a conventional label. Inline addons stay beside the flexible control; block addons occupy their own row.

## Behavior & Accessibility

The editable child remains a native input or textarea. Give it its own accessible name; decorative addons do not add tab stops. Group focus and invalid styles follow the contained control.
