Built on the shadcn Button's **new-york** style and **Radix** primitives, with Vandor's press feedback powered by `motion/react`. The six variants, eight sizes, focus styles, and `asChild` composition remain available.

The Button scales down to `0.96` while pressed and returns to its original size when released. It does not include the audio or haptic feedback used by the website's internal Button.

## Installation

Initialize shadcn in your React project, then install the Button from the Vandor UI registry:

```bash
npx shadcn@latest add https://vandor-ui.vercel.app/r/button.json
```

The registry declares `class-variance-authority`, `radix-ui`, `motion`, and shadcn's `utils` helper as dependencies. The Motion package is named `motion`; the component imports from `motion/react`. The Button uses your project's existing shadcn theme tokens.

The default installation target is `components/ui/button.tsx`. If you already have a Button there, review the CLI's overwrite prompt before replacing local customizations.

## Usage

```tsx
import { Button } from "@/components/ui/button";

export function Demo() {
  return <Button variant="outline">Button</Button>;
}
```

Use your project's configured UI alias if it differs from `@/components/ui`.

## Press Feedback

Press and hold a Button in the playground to try the scale feedback. Pointer presses and keyboard Enter presses use Motion's `whileTap` gesture. The scale transition takes `0.12` seconds and returns on release or cancellation, including when using `asChild` with a link.

Hover changes to background, text, border, and focus shadow transition smoothly over `200ms` with ease-out timing. These CSS transitions remain separate from Motion's press animation, so the scale feedback stays responsive.

Disabled buttons do not animate. Both press feedback and CSS transitions are disabled when the user prefers reduced motion.

To disable press feedback on an individual Button, pass `whileTap={false}`. Motion animation props, including `whileTap` and `transition`, are supported. Animation and drag callbacks use Motion's API rather than the corresponding native DOM animation/drag events.

```tsx
<Button whileTap={false}>No scale feedback</Button>
```

## Sizes

Use `xs`, `sm`, `default`, or `lg` for text buttons. Icon-only buttons use `icon-xs`, `icon-sm`, `icon`, or `icon-lg`. Give icon-only buttons an accessible label.
