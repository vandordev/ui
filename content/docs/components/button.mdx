Vandor UI's Button combines a subtle raised finish, smooth hover transitions, and configurable press feedback. Six variants, eight sizes, and `asChild` composition.

## Playground

Adjust the controls to update the preview and code. **While Tap** toggles press feedback; **Tap Scale** adjusts `whileTap.scale` from `0.80` to `1.00`. Reset restores the defaults.

## Installation

Initialize shadcn in your React project, then install the Button from the Vandor UI registry:

```bash
npx shadcn@latest add https://vandor-ui.vercel.app/r/button.json
```

The default installation target is `components/ui/button.tsx`. If you already have a Button there, review the CLI's overwrite prompt before replacing local customizations.

## Usage

```tsx
import { Button } from "@/components/ui/button";

export function Demo() {
  return <Button variant="outline">Button</Button>;
}
```

Use your project's configured UI alias if it differs from `@/components/ui`.

## Press Feedback

The Button scales to `0.96` while pressed and returns on release, with a `0.12s` transition. Hover colors transition over `200ms`. Disabled buttons and reduced-motion preferences disable animation.

Set `whileTap={false}` to turn off press feedback. Motion's animation props and callbacks are supported.

```tsx
<Button whileTap={false}>No scale feedback</Button>
```

## Variants

The six built-in variants are `default`, `secondary`, `outline`, `ghost`, `destructive`, and `link`.

Solid variants use a subtle top-to-bottom gradient and thin border, without shadows. Outline keeps its border; ghost and link stay flat. All variants retain a keyboard focus ring.

## Sizes

Use `xs`, `sm`, `default`, or `lg` for text buttons. Icon-only buttons use `icon-xs`, `icon-sm`, `icon`, or `icon-lg`. Give icon-only buttons an accessible label.
