## Usage

```tsx
import { Button } from "@/components/ui/button";

export function Demo() {
  return <Button variant="outline">Button</Button>;
}
```

Use your project's configured UI alias if it differs from `@/components/ui`.

## Examples

### Variants

The six built-in variants are `default`, `secondary`, `outline`, `ghost`, `destructive`, and `link`.

Solid variants use a subtle top-to-bottom gradient and thin border, without shadows. Outline keeps its border; ghost and link stay flat. All variants retain a keyboard focus ring.

### Sizes

Use `xs`, `sm`, `default`, or `lg` for text buttons. Icon-only buttons use `icon-xs`, `icon-sm`, `icon`, or `icon-lg`. Give icon-only buttons an accessible label.

Use `data-icon="inline-start"` or `data-icon="inline-end"` to indicate an icon's position. Icon sizing is handled by the Button.

### Loading

Set `isLoading` while an action is pending. The Button shows the Loading component's default `arc` before its label, becomes disabled, and sets `aria-busy`. Icon-only sizes replace their icon with the spinner and retain the supplied `aria-label`.

```tsx
<Button isLoading={isSaving}>Save</Button>
```

Installing Button also installs Loading through its registry dependency. The loading indicator inherits the button's color and respects reduced-motion preferences. The playground's **Is Loading** toggle updates both the preview and generated code.

<ComponentPreview name="button-loading" title="button-loading.tsx">

</ComponentPreview>

### As Child

Use `asChild` to style a link without nesting it inside a button. The child retains its native link semantics. Use this for navigation, not the `variant="link"` appearance alone.

Base UI's `render` composition is also supported:

```tsx
<Button
  render={<a href="/docs/components" />}
  nativeButton={false}
  variant="outline"
>
  Browse components
</Button>
```

## Behavior & Accessibility

The Button scales to `0.96` while pressed and returns on release, with a `0.12s` transition. Its appearance darkens by 10% while active, preserving the gradient. Hover colors and press brightness transition over `200ms`. Disabled buttons do not darken or animate. Reduced-motion preferences disable scaling and CSS transitions, but retain the instant color feedback.

Set `whileTap={false}` to turn off the press animation. Active color feedback remains enabled. Motion's animation props and callbacks are supported.

```tsx
<Button whileTap={false}>No scale feedback</Button>
```

- Native buttons support Enter and Space activation. The press animation uses Motion's pointer and Enter gestures.
- A visible focus ring identifies keyboard focus. Give icon-only buttons an `aria-label`.
- Buttons default to `type="button"`. Set `type="submit"` for form submission.
- With `asChild`, the child retains its own keyboard behavior and attributes. Use links for navigation; native `disabled` does not disable a link.
- `isLoading` blocks clicks, including on `asChild` links, and disables press feedback. The spinner is decorative; the button retains its accessible name and communicates the pending state through `aria-busy`.
