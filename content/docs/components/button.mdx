This is the official shadcn Button baseline for the **new-york** style and **Radix** primitives. Its variants, sizes, focus styles, and `asChild` behavior are unchanged. The `cn` import uses the standard project helper path, and code formatting follows this repository's conventions.

This registry component does not include the audio or haptic feedback used by the website's internal Button. Vandor-specific customizations will be explored after this baseline.

## Installation

Initialize shadcn in your React project, then install the Button from the Vandor UI registry:

```bash
pnpm dlx shadcn@latest add https://vandor-ui.vercel.app/r/button.json
```

The registry declares `class-variance-authority`, `radix-ui`, and shadcn's `utils` helper as dependencies. The Button uses your project's existing shadcn theme tokens.

The default installation target is `components/ui/button.tsx`. If you already have a Button there, review the CLI's overwrite prompt before replacing local customizations.

## Usage

```tsx
import { Button } from "@/components/ui/button";

export function Demo() {
  return <Button variant="outline">Button</Button>;
}
```

Use your project's configured UI alias if it differs from `@/components/ui`.

## Variants

The six built-in variants are `default`, `secondary`, `outline`, `ghost`, `destructive`, and `link`.

## Sizes

Use `xs`, `sm`, `default`, or `lg` for text buttons. Icon-only buttons use `icon-xs`, `icon-sm`, `icon`, or `icon-lg`. Give icon-only buttons an accessible label.

## With Icons

Use `data-icon="inline-start"` or `data-icon="inline-end"` to indicate an icon's position. Icon sizing is handled by the Button.

## As Child

Use `asChild` to style a link without nesting it inside a button. The child retains its native link semantics. Use this for navigation, not the `variant="link"` appearance alone.
