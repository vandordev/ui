## Usage

```tsx
import { DatePicker } from "@/components/ui/date-picker";

<DatePicker label="Appointment date" value={date} onValueChange={setDate} />;
```

The value is a JavaScript `Date` representing a local calendar day. Set `clearable` to include an explicit clear action.

This follows shadcn's Date Picker composition, not a separate upstream DatePicker registry component. It uses Vandor's new animated Popover. `motion={false}` disables popup, Calendar, and button animations; system reduced-motion preferences take priority. Popup reveal takes 180ms and dismissal 120ms. There is no delayed commit.

## Consumer setup

Requires React 19.2+, Tailwind CSS 4 with shadcn theme tokens, and the declared dependencies. CLI installation includes Button (and its Loading files), Calendar, and Popover; review existing primitive overwrite prompts. Copying Source alone is insufficient for manual installation: install these registry dependencies too. No additional animation stylesheet is needed.

## Behavior & Accessibility

Selecting an allowed day commits immediately and closes the popup. Escape dismisses and returns focus to the trigger. `disabledDates` and month-navigation bounds are separate controls. Display formatting does not change the underlying date.

Opening starts on the selected date's month and focuses an eligible date. The popup has an accessible title; the trigger's name includes its label and displayed value. Read-only permits inspection/navigation but disables selection and clearing. Disabled prevents trigger interaction. `value` (including explicit `undefined`) is controlled; otherwise `defaultValue` initializes internal state. `open`/`onOpenChange` independently control visibility.

This is not a native form input: serialize your date explicitly. Dates use local calendar days; avoid converting local midnight to UTC without a deliberate timezone policy. The public API is restricted to the listed props, not arbitrary native input attributes. Playground Reset clears selection and closes the popup; generated code reproduces configuration rather than transient selection.
