## Usage

```tsx
import { InputSecret } from "@/components/ui/input-secret";

<InputSecret label="API secret" defaultValue="vnd_live_example" />;
```

Use for values that should be hidden by default but may be intentionally revealed or copied.

## Behavior & Accessibility

Visibility and copy actions are separately named. Copy success and failure are announced without placing the secret in status text. Clipboard access may be unavailable or denied; no fallback displays the secret elsewhere.
