## Usage

```tsx
import { Drawer, DrawerBody, DrawerFooter } from "@/components/ui/drawer";

export function ProjectSettings() {
  return (
    <Drawer
      trigger={<button type="button">Open settings</button>}
      title="Project settings"
      description="Manage the details and preferences for this project."
    >
      {({ close }) => (
        <>
          <DrawerBody>Your settings go here.</DrawerBody>
          <DrawerFooter>
            <button type="button" onClick={close}>
              Done
            </button>
          </DrawerFooter>
        </>
      )}
    </Drawer>
  );
}
```

The registry installs editable source into your project. Use your configured UI alias if it differs from `@/components/ui`.

## Panel API

`Drawer` owns the trigger, portal, optional backdrop, swipeable panel, header, and built-in X. Only the optional trigger occupies space in the page; the panel renders through a portal. The public API has one panel composition, not a separate root/content composition.

| Prop               | Purpose                                                                                                                                           |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `title`            | Required meaningful accessible title. Accepts a React node.                                                                                       |
| `description`      | Optional supporting content.                                                                                                                      |
| `trigger`          | Optional React element composed into one associated Base UI trigger. Custom button components must forward their ref and native button props.     |
| `children`         | Panel content, or a function receiving `DrawerControl`.                                                                                           |
| `contentProps`     | Panel props, including `className`, `ref`, `finalFocus`, `showCloseButton`, and `closeButtonLabel`. Children belong to `Drawer`, not this object. |
| State and behavior | `control`, `open`, `defaultOpen`, `onOpenChange`, `modal`, `swipeDirection`, snap points, and other supported Base UI root props.                 |

`DrawerBody` and `DrawerFooter` are the layout helpers for panel content. They forward native `div` props and refs. `Drawer` does **not** automatically wrap children in `DrawerBody`, so a form can own both its scrolling body and stationary footer.

The top-right X is visible by default, with a compact 32px button and a 16px icon. The header reserves space for it. Use `contentProps={{ closeButtonLabel: "Close settings" }}` to translate its accessible label. Set `showCloseButton: false` only when supplying another visible dismissal control.

### Migration from the Compound API

This is a breaking API change. Replace the old root, trigger, content, and header composition with `Drawer` props. `DrawerPanel` is now named `Drawer`, without a compatibility alias. Primitive components such as `DrawerContent`, `DrawerTrigger`, and `DrawerHeader` are internal and no longer exported. Replace action buttons using the old close primitive with `useDrawer().close()` or the children render function.

## Direction and Snap Points

The default `swipeDirection` is `right`. Set it to `left`, `up`, or `down` for the other edges. Side panels have a responsive width capped at `28rem`; vertical panels use the available viewport height.

```tsx
<Drawer
  title="Settings"
  trigger={<button type="button">Open</button>}
  swipeDirection="down"
  snapPoints={[0.5, 0.9]}
  showSwipeHandle
>
  <DrawerBody>Your settings</DrawerBody>
</Drawer>
```

Base UI manages the active snap point and swipe gestures. Snap points are fractions between `0` and `1` and are most useful with vertical panels. `showSwipeHandle` adds an optional visual grabber, not a replacement for the gesture area.

## Controlled State and Modal Behavior

Use `defaultOpen` for an initially open, uncontrolled panel. Use `open` and `onOpenChange` when application state must control it. Base UI root props, including `disabled`, `actionsRef`, and change event details, are forwarded.

```tsx
"use client";

import { useState } from "react";
import { Drawer, DrawerBody } from "@/components/ui/drawer";

export function ControlledDrawer() {
  const [open, setOpen] = useState(false);
  return (
    <Drawer
      title="Settings"
      trigger={<button type="button">Open settings</button>}
      open={open}
      onOpenChange={setOpen}
    >
      <DrawerBody>Your settings</DrawerBody>
    </Drawer>
  );
}
```

Panels are modal by default, with a backdrop and modal focus management. Set `modal={false}` only when the surrounding interface should remain interactive. Non-modal panels omit the backdrop; provide suitable dismissal and focus behavior.

## Scrollable Body

`DrawerBody` uses `min-h-0 flex-1 overflow-y-auto`. The panel constrains its height to the viewport, so only the body scrolls. The header, footer, and X remain outside its scroll area.

```tsx
<Drawer title="Settings" trigger={<button type="button">Open settings</button>}>
  {({ close }) => (
    <>
      <DrawerBody>
        {Array.from({ length: 30 }, (_, index) => (
          <p key={index} className="mb-4">
            Setting {index + 1}
          </p>
        ))}
      </DrawerBody>
      <DrawerFooter>
        <button type="button" onClick={close}>
          Done
        </button>
      </DrawerFooter>
    </>
  )}
</Drawer>
```

## Drawer Controls

`useDrawerControl()` creates a stable controller for one mounted Drawer. `useDrawer()` selects the nearest Drawer, including through portals. `useDrawer(control)` selects a specific controller. All return `DrawerControl`:

| Member    | Behavior                                        |
| --------- | ----------------------------------------------- |
| `isOpen`  | Read-only reactive state of the mounted Drawer. |
| `open()`  | Requests opening through Base UI.               |
| `close()` | Requests closing through Base UI.               |

### Control from Outside

Omit `trigger` when the opener lives elsewhere. An ordinary external button is not an associated trigger, so explicitly restore focus with `contentProps.finalFocus`.

```tsx
"use client";

import { useRef } from "react";
import { Drawer, DrawerBody, useDrawerControl } from "@/components/ui/drawer";

export function SettingsDrawer() {
  const control = useDrawerControl();
  const opener = useRef<HTMLButtonElement>(null);
  return (
    <>
      <button ref={opener} type="button" onClick={control.open}>
        Open settings
      </button>
      <Drawer
        control={control}
        title="Settings"
        contentProps={{ finalFocus: opener }}
      >
        <DrawerBody>Your settings</DrawerBody>
      </Drawer>
    </>
  );
}
```

### Control from a Child

```tsx
import { useDrawer } from "@/components/ui/drawer";

export function DoneButton() {
  const { close } = useDrawer();
  return (
    <button type="button" onClick={close}>
      Done
    </button>
  );
}
```

Mount this child inside `DrawerBody` or `DrawerFooter`. Children render functions receive the same controller as `useDrawer()`. Call hooks at the top level of a component, never inside the callback.

### Ownership, Nesting, and Lifecycle

- Without `control`, each Drawer owns its state or uses `open` / `onOpenChange`. Nested drawers do not inherit another panel's state.
- `useDrawer()` selects the nearest panel. Use `useDrawer(outerControl)` to target an outer panel. Outside a Drawer, pass a controller or the hook throws.
- One controller binds to one mounted Drawer. Sharing it between simultaneous panels throws. It can be reused after the previous panel unmounts.
- Do not combine `control` with `open`, `defaultOpen`, or `handle`. Types and runtime checks reject ambiguous state ownership. `onOpenChange` remains available for observation or cancellation.
- `isOpen` is false before attachment and after unmount. Actions without a mounted panel are ignored, not queued. Base UI emits a development warning.
- `open()` and `close()` emit `onOpenChange` with reason `imperative-action`. `details.cancel()` can reject a request without desynchronizing the controller.
- In controlled mode, `close()` requests a change; the panel stays open until its parent updates `open`.
- `close()` returns void, not an exit-animation promise. Use `onOpenChangeComplete` to wait for animation completion.
- Panel children normally mount when opened. Use `contentProps.keepMounted` when state must survive closure; reset form values explicitly when changing the edited record.

```tsx
<Drawer
  title="Settings"
  control={control}
  onOpenChange={(nextOpen, details) => {
    if (!nextOpen && hasUnsavedChanges) details.cancel();
  }}
>
  <DrawerBody>Your settings</DrawerBody>
</Drawer>
```

## Forms with a Stationary Footer

Keep the native form **around** `DrawerBody` and `DrawerFooter`, not inside the body. Give it `flex min-h-0 flex-1 flex-col`. No DrawerForm abstraction or form-library dependency is needed. Never nest a second form around an application form wrapper; apply these classes to that wrapper instead. Any DOM wrapper in the flex chain must also preserve the constrained height.

```tsx
"use client";

import { useId, useState } from "react";
import type { FormEvent } from "react";
import {
  Drawer,
  DrawerBody,
  DrawerFooter,
  useDrawer,
} from "@/components/ui/drawer";

export function EditProjectDrawer({
  save,
}: {
  save: (name: string) => Promise<void>;
}) {
  return (
    <Drawer
      trigger={<button type="button">Edit project</button>}
      title="Edit project"
    >
      <ProjectForm save={save} />
    </Drawer>
  );
}

function ProjectForm({ save }: { save: (name: string) => Promise<void> }) {
  const { close } = useDrawer();
  const nameId = useId();
  const [pending, setPending] = useState(false);
  const [error, setError] = useState<string | null>(null);
  async function handleSubmit(event: FormEvent<HTMLFormElement>) {
    event.preventDefault();
    if (pending) return;
    const name = String(new FormData(event.currentTarget).get("name") ?? "");
    setPending(true);
    setError(null);
    try {
      await save(name);
      close();
    } catch {
      setError("Could not save. Please try again.");
    } finally {
      setPending(false);
    }
  }
  return (
    <form
      className="flex min-h-0 flex-1 flex-col"
      onSubmit={handleSubmit}
      aria-busy={pending}
    >
      <DrawerBody>
        <label htmlFor={nameId}>Project name</label>
        <input id={nameId} name="name" required disabled={pending} />
        {error && <p role="alert">{error}</p>}
      </DrawerBody>
      <DrawerFooter>
        <button type="submit" disabled={pending}>
          {pending ? "Saving…" : "Save"}
        </button>
        <button type="button" onClick={close} disabled={pending}>
          Cancel
        </button>
      </DrawerFooter>
    </form>
  );
}
```

The form owns validation, loading, errors, and persistence. It closes only after saving succeeds. To block closing during a mutation, use `onOpenChange` and `details.cancel()`. Disabling Cancel alone does not block Escape, swipe, the backdrop, or X.

### React Hook Form

Use your application's installed `react-hook-form`. `FormProvider` adds context without a DOM wrapper. Mount this component as a child of Drawer:

```tsx
"use client";

import { useId } from "react";
import { FormProvider, useForm } from "react-hook-form";
import { DrawerBody, DrawerFooter, useDrawer } from "@/components/ui/drawer";

export function ReactHookFormFields({
  save,
}: {
  save: (values: { name: string }) => Promise<void>;
}) {
  const form = useForm({ defaultValues: { name: "" } });
  const nameId = useId();
  const { close } = useDrawer();
  const { errors, isSubmitting } = form.formState;
  const submit = form.handleSubmit(async (values) => {
    form.clearErrors("root");
    try {
      await save(values);
      close();
    } catch {
      form.setError("root", { message: "Could not save. Please try again." });
    }
  });
  return (
    <FormProvider {...form}>
      <form
        className="flex min-h-0 flex-1 flex-col"
        onSubmit={submit}
        aria-busy={isSubmitting}
      >
        <DrawerBody>
          <label htmlFor={nameId}>Project name</label>
          <input
            id={nameId}
            {...form.register("name", { required: "Enter a project name." })}
            aria-invalid={!!errors.name}
          />
          {errors.name && <p role="alert">{errors.name.message}</p>}
          {errors.root && <p role="alert">{errors.root.message}</p>}
        </DrawerBody>
        <DrawerFooter>
          <button type="submit" disabled={isSubmitting}>
            Save
          </button>
          <button type="button" onClick={close} disabled={isSubmitting}>
            Cancel
          </button>
        </DrawerFooter>
      </form>
    </FormProvider>
  );
}
```

### TanStack Form

Use your application's installed `@tanstack/react-form`. Subscribe to footer state without moving it outside the native form. Mount this component inside Drawer:

```tsx
"use client";

import { useId, useState } from "react";
import { useForm } from "@tanstack/react-form";
import { DrawerBody, DrawerFooter, useDrawer } from "@/components/ui/drawer";

export function TanStackFormFields({
  save,
}: {
  save: (values: { name: string }) => Promise<void>;
}) {
  const { close } = useDrawer();
  const nameId = useId();
  const [error, setError] = useState<string | null>(null);
  const form = useForm({
    defaultValues: { name: "" },
    onSubmit: async ({ value }) => {
      setError(null);
      try {
        await save(value);
        close();
      } catch {
        setError("Could not save. Please try again.");
      }
    },
  });
  return (
    <form
      className="flex min-h-0 flex-1 flex-col"
      onSubmit={(event) => {
        event.preventDefault();
        event.stopPropagation();
        void form.handleSubmit();
      }}
    >
      <DrawerBody>
        <form.Field
          name="name"
          validators={{
            onChange: ({ value }) =>
              value.trim() ? undefined : "Enter a project name.",
          }}
        >
          {(field) => (
            <>
              <label htmlFor={nameId}>Project name</label>
              <input
                id={nameId}
                name={field.name}
                value={field.state.value}
                onBlur={field.handleBlur}
                onChange={(event) => field.handleChange(event.target.value)}
                aria-invalid={!field.state.meta.isValid}
              />
              {field.state.meta.errors.map((message, index) => (
                <p key={index} role="alert">
                  {message}
                </p>
              ))}
            </>
          )}
        </form.Field>
        {error && <p role="alert">{error}</p>}
      </DrawerBody>
      <DrawerFooter>
        <form.Subscribe
          selector={(state) => [state.canSubmit, state.isSubmitting]}
        >
          {([canSubmit, isSubmitting]) => (
            <>
              <button type="submit" disabled={!canSubmit || isSubmitting}>
                Save
              </button>
              <button type="button" onClick={close} disabled={isSubmitting}>
                Cancel
              </button>
            </>
          )}
        </form.Subscribe>
      </DrawerFooter>
    </form>
  );
}
```

For forms reused outside drawers, pass `onSuccess={close}` through Drawer's render function instead of calling `useDrawer()` in the form. Choose **panel-form** and enable **Long content** in the playground to inspect the stationary footer.

## Accessibility and Interaction

- Base UI supplies dialog semantics, focus management, Escape dismissal, and focus restoration to the associated trigger.
- `title` supplies the accessible name; `description` adds supporting context, not a replacement for the title.
- Triggers and action buttons must be keyboard-operable. Icon-only buttons require an accessible label.
- Keep a visible dismissal control even when swipe is available. The built-in X has a keyboard focus ring and accessible label.
- Touch users can drag toward the closing edge. The backdrop follows swipe progress; reduced-motion preferences disable transitions.
- Keep long content inside DrawerBody. The portal stays in the caller's theme scope, preserving inherited tokens and nested panels.

See the [Base UI Drawer API](https://base-ui.com/react/components/drawer) for underlying behavior and root props.
