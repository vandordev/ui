## Usage

Use `SelectInput` for a ready-to-use control. It renders the trigger, popup, options, and groups using the same Select primitives.

```tsx
import { SelectInput } from "@/components/ui/select";

const data = [
  { label: "Apple", value: "apple" },
  { label: "Banana", value: "banana" },
];

export function Demo() {
  return (
    <SelectInput
      data={data}
      aria-label="Fruit"
      placeholder="Select a fruit"
      className="w-56"
    />
  );
}
```

`className`, `size`, and `aria-*` props apply to the trigger. Use `triggerProps` for additional trigger attributes, event handlers, or a ref. Use `contentProps` for popup positioning and styling. Root props such as `value`, `defaultValue`, `onValueChange`, `name`, `required`, and `multiple` are forwarded to Select. `data` is the single source for option rendering and selected labels; do not also pass `items` or `children`.

### Custom Composition

The existing primitives remain available when you need a custom trigger, value display, or popup layout.

```tsx
import {
  Select,
  SelectContent,
  SelectGroup,
  SelectItem,
  SelectTrigger,
  SelectValue,
} from "@/components/ui/select";

const items = [
  { label: "Apple", value: "apple" },
  { label: "Banana", value: "banana" },
];

export function Demo() {
  return (
    <Select items={items}>
      <SelectTrigger aria-label="Fruit" className="w-56">
        <SelectValue placeholder="Select a fruit" />
      </SelectTrigger>
      <SelectContent>
        <SelectGroup>
          {items.map((item) => (
            <SelectItem key={item.value} value={item.value}>
              {item.label}
            </SelectItem>
          ))}
        </SelectGroup>
      </SelectContent>
    </Select>
  );
}
```

Use your project's configured UI alias if it differs from `@/components/ui`. Pass `items` to map stored values to readable labels.

### Sizes and Disabled Options

Use `size="sm"` on `SelectTrigger` for a compact control. Set `disabled` on `Select` to disable the whole control, or on individual `SelectItem` elements to disable options.

### Groups

`SelectInput` accepts options and groups in the same array, preserving their order. A group uses `label` and `items`; an option uses `label`, `value`, and optionally `disabled`.

```tsx
const data = [
  { label: "Apple", value: "apple" },
  {
    label: "Tropical",
    items: [
      { label: "Mango", value: "mango" },
      { label: "Banana", value: "banana", disabled: true },
    ],
  },
];

<SelectInput data={data} aria-label="Fruit" placeholder="Select a fruit" />;
```

Groups support one level only. Use unique group labels and option values across the control. Labels are strings and values are strings or numbers. Readonly arrays are supported. An empty array renders no options and still displays the placeholder when no value is selected.

Place options inside `SelectGroup`. Use `SelectLabel` for a group heading and `SelectSeparator` between groups. Group headings do not label the control: give the trigger a visible label or `aria-label`.

### Custom Option Content

Use `renderItem` to add icons or other non-interactive content. The option's original `label` remains the selected text and keyboard typeahead label.

```tsx
<SelectInput
  data={data}
  aria-label="Fruit"
  renderItem={(item) => <span>{item.label}</span>}
  contentProps={{ side: "top", align: "end" }}
/>
```

Set `size="sm"`, `disabled`, or `animated={false}` directly on `SelectInput`. For searchable or very large lists, prefer a Combobox instead of extending Select with search.

### Controlled Values and Forms

Use `value` and `onValueChange` on `Select` for controlled selection, or `defaultValue` for an initial uncontrolled value. Set `name` to include the value in form submission. Base UI's generic value and multiple-selection APIs are preserved.

## Motion & Accessibility

The trigger uses a subtle vertical gradient, a pointer cursor, and press feedback matching Button: it scales to `0.96` and darkens by 10% while pressed, with a `120ms` ease-out transition. Disabled triggers show a not-allowed cursor and do not scale or darken. Reduced-motion preferences disable scaling and transitions while retaining instant color feedback. Options use a pointer cursor; disabled options show a not-allowed cursor and remain unselectable.

The option menu fades and scales from `0.96` to `1` over `180ms` with an ease-out curve. Closing reverses the effect over `120ms`, keeping the popup mounted until Motion finishes. Options remain immediately interactive, without staggered delays.

- Reduced-motion preferences disable scaling and animation duration.
- Set `animated={false}` on `SelectContent` for an instant reveal and close.
- Menus open below the trigger by default. Set `alignItemWithTrigger` to overlap the trigger and align the selected item.
- Base UI preserves Arrow-key navigation, typeahead, Enter/Space selection, Escape dismissal, and focus restoration.
- Long lists scroll within the available viewport height, with scroll-arrow affordances.
- Give every control an accessible name using a visible label or `aria-label` on `SelectTrigger`.
