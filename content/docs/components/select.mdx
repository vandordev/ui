## Usage

Use `Select` for a ready-to-use control. It renders the trigger, popup, options, and groups automatically.

```tsx
import { Select } from "@/components/ui/select";

const data = [
  { label: "Apple", value: "apple" },
  { label: "Banana", value: "banana" },
];

export function Demo() {
  return (
    <Select
      data={data}
      aria-label="Fruit"
      placeholder="Select a fruit"
      className="w-56"
    />
  );
}
```

`className` and `aria-*` props apply to the trigger. `size` controls the built-in trigger's height. Use `triggerProps` for additional trigger attributes, event handlers, or a ref. Use `contentProps` for popup positioning and styling. Root props such as `value`, `defaultValue`, `onValueChange`, `name`, `required`, and `multiple` are forwarded to Base UI. `data` is the single source for option rendering and selected labels; do not also pass `items` or `children`.

### Custom Trigger

Pass a `trigger` element for fixed content, or a callback to display the current selection. Select attaches Base UI's trigger behavior to the element without adding a wrapper button, default styling, press animation, or chevron.

```tsx
import { Button } from "@/components/ui/button";
import { Select } from "@/components/ui/select";

<Select
  data={data}
  aria-label="Fruit"
  placeholder="Select a fruit"
  trigger={({ selectedLabel, placeholder, open }) => (
    <Button variant="outline" aria-label="Fruit">
      {selectedLabel ?? placeholder}
      <span aria-hidden="true">{open ? "▴" : "▾"}</span>
    </Button>
  )}
/>;
```

The callback receives `value`, `selectedLabel`, `placeholder`, `open`, and `disabled`. `selectedLabel` is `null` when no data option matches; multiple labels are joined with `", "` in selected-value order. An empty-string label is preserved. Both controlled and uncontrolled selection are supported.

The callback must return a React element, not text or a fragment. Custom components must forward props and ref to a single interactive element. Prefer a native button; for non-button triggers, set `triggerProps={{ nativeButton: false }}` and provide appropriate styling. Keep custom trigger content non-interactive. `triggerProps.render` is not accepted: use `trigger` instead.

### Advanced Composition

The existing primitives remain available when you need a custom trigger, value display, or popup layout.

```tsx
import {
  SelectRoot,
  SelectContent,
  SelectGroup,
  SelectItem,
  SelectTrigger,
  SelectValue,
} from "@/components/ui/select";

const items = [
  { label: "Apple", value: "apple" },
  { label: "Banana", value: "banana" },
];

export function Demo() {
  return (
    <SelectRoot items={items}>
      <SelectTrigger aria-label="Fruit" className="w-56">
        <SelectValue placeholder="Select a fruit" />
      </SelectTrigger>
      <SelectContent>
        <SelectGroup>
          {items.map((item) => (
            <SelectItem key={item.value} value={item.value}>
              {item.label}
            </SelectItem>
          ))}
        </SelectGroup>
      </SelectContent>
    </SelectRoot>
  );
}
```

Use your project's configured UI alias if it differs from `@/components/ui`. Pass `items` to map stored values to readable labels.

### Sizes and Disabled Options

Use `size="sm"` on `Select` for a compact built-in trigger. Set `disabled` on `Select` to disable the whole control, or on individual data options to disable them. For advanced composition, use `SelectTrigger` and `SelectItem` respectively.

### Groups

`Select` accepts options and groups in the same array, preserving their order. A group uses `label` and `items`; an option uses `label`, `value`, and optionally `disabled`.

```tsx
const data = [
  { label: "Apple", value: "apple" },
  {
    label: "Tropical",
    items: [
      { label: "Mango", value: "mango" },
      { label: "Banana", value: "banana", disabled: true },
    ],
  },
];

<Select data={data} aria-label="Fruit" placeholder="Select a fruit" />;
```

Groups support one level only. Use unique group labels and option values across the control. Labels are strings and values are strings or numbers. Readonly arrays are supported. An empty array renders no options and still displays the placeholder when no value is selected.

Place options inside `SelectGroup`. Use `SelectLabel` for a group heading and `SelectSeparator` between groups. Group headings do not label the control: give the trigger a visible label or `aria-label`.

### Custom Option Content

Use `renderItem` to add icons or other non-interactive content. Additional option fields are inferred and available in the callback. The option's original `label` remains the built-in trigger text and keyboard typeahead label. Select still owns the option wrapper, selected indicator, groups, scrolling, portal, and popup; arbitrary popup children are not accepted.

```tsx
<Select
  data={data}
  aria-label="Fruit"
  renderItem={(item) => <span>{item.label}</span>}
  contentProps={{ side: "top", align: "end" }}
/>
```

Set `size="sm"`, `disabled`, or `animated={false}` directly on `Select`. `animated` controls popup reveal and exit only. The built-in trigger retains its press feedback; custom triggers own their styling and motion. For searchable or very large lists, prefer a Combobox instead of extending Select with search.

### Controlled Values and Forms

Use `value` and `onValueChange` on `Select` for controlled selection, or `defaultValue` for an initial uncontrolled value. Set `name` to include the value in form submission. Base UI's generic value and multiple-selection APIs are preserved.

## Motion & Accessibility

The trigger uses a subtle vertical gradient, a pointer cursor, and press feedback matching Button: it scales to `0.96` and darkens by 10% while pressed, with a `120ms` ease-out transition. Disabled triggers show a not-allowed cursor and do not scale or darken. Reduced-motion preferences disable scaling and transitions while retaining instant color feedback. Options use a pointer cursor; disabled options show a not-allowed cursor and remain unselectable.

The option menu fades and scales from `0.96` to `1` over `180ms` with an ease-out curve. Closing reverses the effect over `120ms`, keeping the popup mounted until Motion finishes. Options remain immediately interactive, without staggered delays.

- Reduced-motion preferences disable scaling and animation duration.
- Set `animated={false}` on `SelectContent` for an instant reveal and close.
- Menus open below the trigger by default. Set `alignItemWithTrigger` to overlap the trigger and align the selected item.
- Base UI preserves Arrow-key navigation, typeahead, Enter/Space selection, Escape dismissal, and focus restoration.
- Long lists scroll within the available viewport height, with scroll-arrow affordances.
- Give every control an accessible name using a visible label or `aria-label` on `SelectTrigger`.

## Migration

`SelectInput` is now `Select`, with the same `data`-driven usage. The previous compositional `Select` is now `SelectRoot`; its child primitives remain available. Update imports and JSX names accordingly. `SelectInput` is no longer exported.
